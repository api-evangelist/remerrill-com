## API

- Line finder, deterministic pump line selection: POST
  https://www.remerrill.com/api/line-finder with a JSON duty
  ({ fluid, concentrationPct?, temperatureF?, flowGpm? or flowGph?,
  pressurePsi? or headFt?, service? }). Returns which represented lines
  fit and why, with source citations, plus an RFQ link. Verdicts come
  only from curated tables of manufacturer-published data (currently
  Grundfos dosing and Continental progressing cavity; the other lines
  are consult-REM by design). Fluid, concentration, and temperature are
  never resolved by the endpoint; chemical compatibility is confirmed by
  an REM engineer. Anything unresolved returns consult-REM, never a
  guess.
  Example: curl -X POST https://www.remerrill.com/api/line-finder -H 'Content-Type: application/json' -d '{"fluid":"sodium hypochlorite","concentrationPct":12.5,"flowGph":2,"pressurePsi":40,"service":"feed"}'
- A2A endpoint, the same line finder over the Agent2Agent protocol v1.0:
  JSON-RPC 2.0 at POST https://www.remerrill.com/api/a2a (method
  SendMessage; send the duty JSON as a message part). Synchronous,
  stateless: a resolvable duty returns a completed task whose artifact
  carries the exact line-finder response plus a text summary. No
  streaming, no push notifications.
  Example: curl -X POST https://www.remerrill.com/api/a2a -H 'Content-Type: application/json' -H 'A2A-Version: 1.0' -d '{"jsonrpc":"2.0","id":1,"method":"SendMessage","params":{"message":{"messageId":"m1","role":"ROLE_USER","parts":[{"data":{"fluid":"sodium hypochlorite","concentrationPct":12.5,"flowGph":2,"pressurePsi":40,"service":"feed"}}]}}}'
